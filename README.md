# Password Strength Checker

## About the Project

This is my first cybersecurity internship project with DecodeLabs.

The project is a simple Python program that checks the strength of a password based on four basic requirements:

- At least 8 characters
- Contains an uppercase letter
- Contains a number
- Contains a symbol

The program then gives the password a strength rating of:

- Weak
- Medium
- Strong

## How It Works

The program checks each password requirement and gives one point for every requirement that is met.

The final score determines the password strength.

## Testing

I tested the program with different fictional passwords:

| Test Password | Expected Result |
|---|---|
| `hello` | Weak |
| `CyberTest123` | Medium |
| `CyberTest123@` | Strong |

The program correctly classified the test passwords.
